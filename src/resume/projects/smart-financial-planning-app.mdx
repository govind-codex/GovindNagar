The Smart Financial Planning App helps users track budgets, manage expenses, monitor financial goals, and process financial data through connected frontend and backend workflows.

## What it does

- Built backend services for budget tracking, expense management, and financial goal monitoring using **Express.js**.
- Designed normalized **MySQL** schemas, implemented joins, constraints, and validations to support data integrity and efficient querying.
- Integrated the frontend with backend APIs for real-time financial data processing.
- Implemented business logic for expense categorization, budget limit validation, and transaction handling.

## Tech focus

This project combines frontend integration with backend API design and relational database modeling, with emphasis on validation and practical financial workflows.
