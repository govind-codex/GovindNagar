The Asset Management System is a REST API project built to manage how assets are allocated, returned, tracked, and reported across their lifecycle.

## What it does

- Designed and developed RESTful backend APIs for asset allocation, returns, tracking, and lifecycle management.
- Implemented role-based access control, asset status validation using **Mongoose enums**, and secure routes using **JWT authentication**.
- Optimized database queries and implemented aggregation pipelines to generate asset summary reports and assignment statistics.
- Followed MVC architecture, modular folder structure, and reusable services to keep the codebase scalable and maintainable.

## Tech focus

This project highlights backend application structure: clean routes, controllers, services, validation, authentication, and MongoDB data modeling.
